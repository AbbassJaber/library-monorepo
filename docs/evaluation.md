# Evaluation

The AI features are measured, not just demoed: every suite runs on the deterministic Mock in CI
(gated) and on the real providers on request (reported, with a cost cap). Agent cases are split
into a tuned set and a hold-out set the prompts and the judge were never tuned on. How each
number was reached, and what changed because of it, is in [DECISIONS.md](../DECISIONS.md).

```sh
pnpm eval                                              # nl-search on the Mock (gated, free)
pnpm eval --suite autofill                             # Mock over recorded Open Library answers (gated)
pnpm eval --suite injection                            # 26 prompt-injection attacks (0 violations gated, every provider)
pnpm eval --suite retrieval --target http --mode all   # lexical vs hybrid vs hybrid + rerank, running API
pnpm eval --suite retrieval --target http --mode calibrate   # semantic cutoff sweep (server at HYBRID_MIN_SIMILARITY=0)
EVAL_MAX_COST_USD=3 pnpm eval --provider bedrock --cache-padding both   # real Haiku, both prompts
EVAL_MAX_COST_USD=3 pnpm eval --suite autofill --provider bedrock --lookup openlibrary  # real Haiku, live lookups
EVAL_MAX_COST_USD=1.5 pnpm eval --suite injection --provider bedrock   # worst case $1.34 (6 agent turns); real ~$0.11
pnpm eval --suite agent                                # agent chat on the Mock: deterministic rubric (gated)
EVAL_MAX_COST_USD=2 pnpm eval --suite agent --provider bedrock --cases all   # chat on Haiku (small tier), tuned + hold-out, Haiku judge
EVAL_MAX_COST_USD=2 pnpm eval --suite agent --provider kimi --tier strong     # the same on Kimi K3
pnpm eval --suite recommend                            # explained recommendations on the Mock (allowlist gated)
EVAL_MAX_COST_USD=0.5 pnpm eval --suite recommend --provider bedrock   # 12 reader profiles on Haiku
pnpm eval --suite voice                                # 21 spoken fixtures through full sessions on the scripted voice (gated)
VOICE_MODEL=amazon.nova-2-sonic-v1:0 EVAL_MAX_COST_USD=1 pnpm eval --suite voice --voice nova-sonic   # real Nova 2 Sonic
pnpm eval:docs                                         # rewrite the tables below from results/
```

A paid run prints its worst-case cost first and refuses (exit 2) above `EVAL_MAX_COST_USD`
(default 3). The Mock, the lexical baseline and the injection violations are gated (exit 1);
real-provider quality is reported, not gated. Throttle retries count Bedrock `429`s (account
quota), never quality.

The headline numbers are in the [README](../README.md#evaluation); every table they come from is
below.
